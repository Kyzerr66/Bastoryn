COMMANDES
Clique une carte, puis un sol libre pour construire. Tu peux aussi glisser la carte.
Un message rouge et une croix signalent un emplacement interdit ; aucun coût
n'est prélevé en cas de refus. Le cercle large indique la portée, pas la taille.
Touches 1 à 6 : sélectionner une défense. Échap : annuler la sélection.
Glisser le terrain : déplacer la caméra. Molette / pincement / + et − : zoomer.
La minicarte permet de rejoindre un point. Le bouton Carte l’agrandit.
Le bouton Château recentre la vue. Le bouton Plein écran apparaît si disponible.
Sur téléphone : touche une carte puis le terrain pour poser, glisse pour déplacer
la vue et pince pour zoomer. La rotation adapte le HUD sans arrêter la partie ;
une pose en cours est annulée pour éviter un clic involontaire.
En rendu compatible, les flèches courbes tournent la vue pour voir les volumes.
Cliquer une défense posée permet de consulter ses statistiques et de l'améliorer.
Les étiquettes de colline disparaissent après construction pour ne pas la masquer.

ESCARMOUCHES
Toutes les cartes et difficultés sont disponibles dès le départ en escarmouche.
Le deck commun garantit les mêmes moyens de départ pour les équipes.
La campagne conserve son deck et sa progression. Les escarmouches ne modifient
pas ses récompenses. Les partenaires d'une même équipe partagent énergie et base.
Chacun garde le contrôle de ses propres défenses.
En opposition, 80 énergie permettent d'envoyer 4 fantassins et 1 blindé.
Recharge : 18 secondes. Les vagues sont synchronisées ; l'hôte peut les anticiper.
Une vague PvP est limitée à 180 secondes. La dernière équipe debout gagne.
Si plusieurs équipes terminent la carte, départage par vie puis éliminations.

MULTIJOUEUR AVEC DE VRAIS AMIS
Le fichier HTML seul ne peut pas relier plusieurs appareils. Le serveur fourni
permet de jouer ensemble ; aucun abonnement ni dépendance npm n'est nécessaire.
Prérequis : une version LTS de Node.js installée sur le PC hôte.

Windows : extrais tout le ZIP et lance OUVRIR_MULTIJOUER.bat.
macOS/Linux : lance ./ouvrir-multijoueur.sh depuis ce dossier,
ou exécute la commande : node server.cjs

1. L'hôte ouvre http://localhost:8787 dans son navigateur.
2. Les amis sur le même réseau ouvrent l'adresse réseau affichée par le serveur.
   Si le système le demande, autorise le serveur sur ton réseau privé.
3. Dans « Amis & salons », choisis ton pseudo puis crée un salon avec le mode,
   la carte et la difficulté souhaités. Les autres utilisent son code.
4. Tous les joueurs se déclarent prêts ; l'hôte lance la partie.
5. Garde le serveur et l'onglet de l'hôte ouverts pendant toute la partie.
   Pour arrêter le serveur : Ctrl+C.

Le lien d'invitation reprend l'adresse utilisée pour ouvrir le jeu. L'hôte doit
ouvrir l'adresse réseau affichée s'il veut copier un lien utilisable par ses amis :
un lien localhost ne mène qu'à l'appareil de la personne qui l'ouvre.

Le coop accepte 2 à 4 humains en salon ; le solo coop est disponible en escarmouche.
Le duel exige 2 joueurs ; le 2 contre 2 et chacun pour soi exigent 4 joueurs.
En 2 contre 2, les places 1–2 affrontent les places 3–4.
Le carnet d'amis est enregistré sur cet appareil ; ce n'est pas un service de
comptes ou de présence en ligne. Transmets toi-même le code ou le lien du salon.
Les salons et parties sont temporaires. Si l'hôte part, le salon est fermé.
Le serveur relaie les actions ; l'hôte simule la partie. Il est conçu pour des
parties privées entre personnes de confiance, sans classement compétitif.

POUR JOUER À DISTANCE
Il faut héberger ce dossier sur un service capable d'exécuter un serveur Node.js
persistant avec connexions SSE. La commande de démarrage est npm start.
Le port peut être défini par la variable PORT. Une adresse HTTPS publique permet
alors à tous d'ouvrir le même jeu et de rejoindre le même salon.
Un hébergement statique seul (par exemple un dépôt de fichiers HTML) sert la
campagne et les IA, mais ne lance pas le serveur multijoueur.
Aucun hébergement public n'est créé par cette livraison.

TERRITOIRES
Les 3 zones proches du château sont disponibles dès le début. Utilise le bouton Territoires pour acheter les autres avec l’énergie et l’influence de la partie. Les achats sont partagés par équipe et réinitialisés à chaque nouvelle partie. Le socle entier doit tenir dans une zone disponible ; les routes restent interdites.

Contrôles HUD vérifiés en 1280×720, 390×844, 844×390, 320×568 et 568×320,
avec rotation pendant la pose et une vague. Pas de mesure FPS sur téléphone physique.
